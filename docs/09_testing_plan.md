# Test strategy and Phase 1 verification

## Active automated suites
- `scripts/tests`: mandatory source ownership, file length/punctuation, requirement register numbering and status discipline.
- `backend/tests/integration/test_auth_flow.py`: registration, login, token rejection, account duplication and safe validation errors.
- `backend/tests/integration/test_project_tenancy.py`: project and site workflow, cross-tenant isolation, invitation acceptance, worker restrictions and Decimal input validation.
- `backend/tests/integration/test_migration_security.py`: live database migration revision, append-only audit triggers and foreign key enforcement.
- `scripts/verify_postgres_migration.py`: PostgreSQL migration, key relationship constraints and direct mutation protection, run in CI's PostgreSQL job.

## Acceptance principles
Tests run from an empty database generated by Alembic rather than a faked API or pre-existing local tables. SQLite tests cover quick application logic, while PostgreSQL provides a separate migration-level reality check. An error must block CI. Regression tests do not mark the broader Phase 1 exit gate passed until validation and architecture approvals are obtained.

## Still missing
Browser and mobile testing, production authorization review, workload and backup tests, account recovery and rate-limit tests, full PostgreSQL API workflow tests, detailed financial reconciliation, evidence upload, offline sync, AI evaluation and claim lifecycle. These belong to their roadmap phases and have not passed.

## Local commands
Run `python -m pip install -e ".[dev]"`, `python -m pytest -q`, `ruff check backend scripts` and `python scripts/check_project_rules.py .`.

## Container end-to-end test

The `docker_configuration` CI job starts disposable PostgreSQL and API containers, applies the Alembic migration, runs `python -m scripts.smoke_docker_api`, and removes the containers and volumes. This proves the synthetic registration-to-project workflow runs in the actual Docker image. The first complete pass was GitHub run 44296887975 on 18 November 2026.
