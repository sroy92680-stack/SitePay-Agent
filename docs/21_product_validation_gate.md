## Interview protocol
Record participant role and permission; observe existing site-to-office evidence flow, measurement process, bill reconciliation, approval chain, rejection reasons, delays, and actual cost or time where the participant can support it. Keep personally identifying and commercial records out of this public GitHub repository.

## Observed claim workflow
Trace evidence received, contractor measurement, Bill of Quantities matching, prior quantity ledger check, document preparation, human sign-off, submission, certification and payment reconciliation. Mark any unknown details as unknown.

## Definition of pass
All mandatory evidence must be verified and reviewed by an authorised owner. The owner records the date, sources, decision and any critical exceptions. If any critical item lacks evidence, this gate stays blocked and Phase 1 does not start. See GitHub issue #1.
